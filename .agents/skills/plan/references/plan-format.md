# plan/PLAN.md format

```markdown
# <nazwa appki> - plan

Start sesji: `git status`, `bun run agent:context`, pierwszy niezaznaczony
punkt poniżej i plik jego kroku. [STOP] = decyzja albo dane od właściciela.

## [Krok 01 - Start i marka](steps/01-start.md)
- [x] 1.1 Repozytorium i nazwa appki
- [ ] 1.2 [STOP] Dane firmy do stopki
- [ ] 1.3 [STOP] Kierunek wyglądu i kolory

## [Krok 02 - Strona główna](steps/02-home.md)
- [ ] 2.1 Plan sekcji
- [ ] 2.2 Teksty
- [ ] 2.3 Zrzuty desktop i mobile
```

Step file `plan/steps/NN-<slug>.md`: `Cel`, `Pliki`, `Pytania`, `Jak
sprawdzić`, `Decyzje`. Up to about a screen of text.
